🎲 Random Number Generator

📌 Description

Random Number Generator est une petite application web qui permet de choisir un nombre aléatoire entre 1 et 24.

Chaque nombre est sélectionné une seule fois. Lorsque tous les nombres ont été utilisés, la liste est automatiquement réinitialisée.

✨ Fonctionnalités

- Générer un nombre aléatoire entre 1 et 24.
- Éviter la répétition des nombres avant la réinitialisation.
- Réinitialiser automatiquement la liste après avoir sélectionné tous les nombres.
- Interface simple et interactive.

🛠️ Technologies utilisées

- HTML5 : structure de la page.
- CSS3 : mise en forme et design.
- JavaScript : génération des nombres aléatoires et gestion des clics.

🚀 Utilisation

1. Ouvrir le fichier "index.html" dans un navigateur.
2. Cliquer sur le bouton Choisir un numéro.
3. Un nombre aléatoire s'affiche à l'écran.
4. Continuer jusqu'à ce que tous les nombres soient sélectionnés.

🎯 Objectif du projet

Pratiquer JavaScript à travers les tableaux, les boucles, les fonctions, "Math.random()", "Math.floor()", "splice()" et les événements "click".
